#  AI To-Do List (Mini Project)

An AI-powered to-do list built using **Next.js**, **Express.js**, and **OpenAI API**.

##  Features
- Add, view, and manage daily tasks
- Get AI suggestions on which tasks to prioritize
- Responsive UI built with Next.js
- Backend powered by Express and OpenAI API

## Tech Stack
- Frontend: Next.js (React)
- Backend: Express.js
- AI: OpenAI GPT-4o-mini
- Language: JavaScript (ES Modules)
